Como contamos

  • Ligados: ônibus que o Olho Vivo lista numa linha, com GPS ativo. Inclui os parados em ponto final e exclui os que estão na garagem.
  • Em movimento: ligados, com posição de no máximo 3 minutos, que andaram pelo menos 50 m desde a leitura anterior. Só é calculado quando a leitura anterior tem até 6 minutos.
  • Parados: ligados menos em movimento. Inclui ônibus no ponto final, em congestionamento parado ou com GPS sem atualizar.
  • Linhas: letreiros distintos (campo c). A API lista cada sentido separado, o que dobraria a conta.
  • Cada leitura é uma foto simultânea, nunca o total de ônibus que rodou no dia. Método baseado em travahacker/analise-onibus.
Fontes: API Olho Vivo (SPTrans) pelo gateway apilib da Prefeitura; Passageiros Transportados (SPTrans). Atualizado a cada 3 minutos.
